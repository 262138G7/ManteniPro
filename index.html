          Referencia de la API REST

          Contrato previsto por el equipo. Estos endpoints no están conectados: este prototipo trabaja solo con datos locales y no realiza ninguna petición al servidor.

          • GET/api/v1/equipos

            Lista los equipos registrados con su ubicación y próxima revisión.

          • POST/api/v1/equipos

            Registra un equipo. Campos obligatorios: nombre, codigo, ubicacion, fecha_proxima_revision.

          • GET/api/v1/mantenimientos/pendientes

            Consulta las órdenes pendientes o con fecha próxima a vencer.

          • PUT/api/v1/ordenes/{id}/estado

            Actualiza el estado (pendiente, en_curso, completada) y las observaciones de una orden.
